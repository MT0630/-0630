# AutoTapper

画面上に置いたターゲットの位置を自動で連打する Android アプリ（Kotlin）。

## ビルドとインストール
1. Android Studio で「Open」→ この `AutoTapper` フォルダを選ぶ
2. Gradle の同期が終わるまで待つ（初回は数分）
3. スマホで「開発者向けオプション」→「USB デバッグ」をオンにして PC に接続
4. Android Studio の ▶（Run）で実機にインストール

## 初回設定
1. アプリを開き「ユーザー補助の設定を開く」→「AutoTapper」をオン
2. Android 13 以降で「制限付き設定」と表示されてオンにできない場合：
   設定 → アプリ → AutoTapper → 右上の︙ →「制限付き設定を許可」→ もう一度オン

## 使い方
- タップ間隔（ミリ秒）を入力 →「連打ボタンを追加」
- 連打したいアプリを開き、ボタンをドラッグして位置を合わせる
- 音量ボタン（下）を押している間だけ連打（緑になる）／離すと停止
- 連打ボタンを長押し → 削除。複数置くと 1→2→3… の順に回る
- 連打ボタンが無いときは音量ボタンは普通に使える

## 仕組み
- `TapService`：ユーザー補助サービス。`onKeyEvent()` で音量ボタンの押下・解放を検知し、`dispatchGesture()` でタップを送信
- `ButtonManager` / `TapButton`：`TYPE_ACCESSIBILITY_OVERLAY` で連打ボタンを表示し、連打ループを管理
  （ユーザー補助のオーバーレイなので「他のアプリの上に重ねて表示」権限は不要）
- 連打中はボタンを `FLAG_NOT_TOUCHABLE` にして、タップが下のアプリに届くようにしている
- 画面を指で押し続ける方式は、実際の指のタッチと自動タップが互いに打ち消し合うため使っていない

## 注意
- Google Play への公開はユーザー補助 API の審査が厳しいため、個人利用（APK 直接インストール）向けです
- ゲーム等で使うとそのサービスの規約違反になる場合があります
